# The toolchain bootstrap

The required ladder is BOOTASM -> ASM0 -> ASM1 -> ASM86 -> IR86 -> RILL0 -> RILLBOOT -> RILL. The final collection implements IR86 and ASM86 in RILL and compares two rebuild generations of all three tools.

Native IR86 has one construction. The initial text translator grows into its streaming, frame-capable implementation. IR86.ASM and IRWIDE.ASM are identical retained names. RILL0 uses that translator; its scanner, 40-byte symbol records, local layout, emitter and parser are extended in place by RB01..RB12. Every continuation retains the complete preceding compiler subset. There are no independent native IR or IR-compiler restarts.

RILL0 starts with one main, local mutable words, +/-, unsigned comparisons, blocks, if/else, while and a few service calls. RILLBOOT adds only what RILL.RIL and its construction use: word arithmetic, masks/right shift, logical negation, strings, globals, buffers, procedures, file/publication services and checked allocated workspace. It omits ^, <<, unary minus, complement, explicit address-of and unused intrinsic wrappers. RILLBOOT builds the RILL compiler; that compiler builds both tool ports. RILL supplies the additional word operators and pointer wrappers used by those sources.

Source extent is independent of output and workspace size. The native assembler streams blocks and retains 8192 symbols in allocated pages. IR and both compiler milestones stream bounded file blocks. Compiler globals, parameters and local records share one stable layout with capacity headroom; no unused grammar is justified by that headroom. COM output is bounded to 61184 bytes.

The first native compiler source and all continuation edits remain required. TMAKE rebuilds RILL0, executes its HI program, builds RILLBOOT, builds R0, uses R0 for the two ports, then rebuilds all three tools twice. Source rejection preserves an accepted result; publication errors retain recovery options. Every copy follows a fresh successful status.

Production evidence is under pub_src/qa/toolchain. review_bootstrap_scope.py --strict requires a successor witness for every accepted assembler/IR operation, a narrow compiler seed and actual continuing source bases. test_compiler_ladder.py executes every stopping test and retained core language through every complete continuation. bootstrap_chain.py starts from canonical BASIC; rebuild.py checks all six generation comparisons. validate_ladder_publication.py reconstructs the printed edits and verifies exact port notebooks, commands and source archives. The separate DOS 3.10 check runs the published batch; historical BASIC compatibility remains qualified in pub_src/README.md.
