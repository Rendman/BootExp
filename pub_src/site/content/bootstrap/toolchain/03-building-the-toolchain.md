The complete ladder is:

```text
GW-BASIC
  BOOTASM
    ASM0
      ASM1
        ASM86
          native streaming IR86
            RILL0
              IR-written RILLBOOT compiler seed
                RILL-written compiler, IR86, and ASM86
                  two matching rebuild generations
```

ASM1 is the streaming-seed collection between ASM0 and ASM86. The [RILLBOOT collection](../../rb/index.html) constructs RILLBOOT, the IR-written compiler seed. The [RILL collection](../../rc/index.html) constructs the compiler in RILL, including its storage and procedure frames, and proves matching self-builds. The final three source programs are RILL.RIL, IR86.RIL, and ASM86.RIL. They share the published language, not a special tool-building escape.

## Reproduce the disk workbench

Begin with the tested native 6433-byte ASM86 preserved as ASMAKEEP.COM. Keep its BASIC/native ladder sources. Copy the source collection to a hard-disk work directory and run:

```dos
TMAKE
```

TMAKE first builds IRWIDE.COM (12301 bytes) with ASMAKEEP. That native translator and assembler rebuild RILL0, then compile and run its HI program. They next build RILLBOOT.COM (22015 bytes) from the authored RILLBOOT.IR. The compiler seed builds the completed RC43 source, RILL.RIL, as RBOOT.COM. RBOOT compiles that unchanged source with sixty-four-slot frames to establish R0.COM. R0 then compiles IR86.RIL and ASM86.RIL, using the native translator and assembler to establish I0 and A0. TMAKE checks every tool status immediately and stops at the first nonzero status. Its visible PASS markers identify the RILL0 program and each completed initial or rebuild pipeline for the three full tools.

The A/I/R letters below mean assembler, IR translator, and RILL compiler:

| Tool | First RILL build | First rebuild | Second rebuild | Bytes |
|---|---|---|---|---|
| ASM86 | A0.COM | A1.COM | A2.COM | 31886 |
| IR86 | I0.COM | I1.COM | I2.COM | 32343 |
| RILL | R0.COM | R1.COM | R2.COM | 27614 |

Each rebuild generation uses the preceding RILL-written compiler, translator, and assembler for **all three source programs**. The preserved native tools are not silently used in that closed loop. TMAKE.BAT is ordinary DOS batch text; it supplies no executable bytes. Its complete source is:

```dos
ECHO OFF
IF NOT EXIST ASMAKEEP.COM GOTO MISSING
ASMAKEEP IRWIDE.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM IRWIDE.COM >NUL
IRWIDE RILL0.IR RESULT.ASM
IF ERRORLEVEL 1 GOTO FAILED
ASMAKEEP RESULT.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM RILL0.COM >NUL
RILL0 TSMALL.RIL RESULT.IR
IF ERRORLEVEL 1 GOTO FAILED
IRWIDE RESULT.IR RESULT.ASM
IF ERRORLEVEL 1 GOTO FAILED
ASMAKEEP RESULT.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM STEST.COM >NUL
STEST
IF ERRORLEVEL 1 GOTO FAILED
ECHO PASS RILL0 PROGRAM
IRWIDE RILLBOOT.IR RESULT.ASM
IF ERRORLEVEL 1 GOTO FAILED
ASMAKEEP RESULT.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM RILLBOOT.COM >NUL
RILLBOOT RILL.RIL RESULT.IR
IF ERRORLEVEL 1 GOTO FAILED
IRWIDE RESULT.IR RESULT.ASM
IF ERRORLEVEL 1 GOTO FAILED
ASMAKEEP RESULT.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM RBOOT.COM >NUL
RBOOT RILL.RIL RESULT.IR
IF ERRORLEVEL 1 GOTO FAILED
IRWIDE RESULT.IR RESULT.ASM
IF ERRORLEVEL 1 GOTO FAILED
ASMAKEEP RESULT.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM R0.COM >NUL
ECHO PASS RILL INITIAL BUILD
R0 IR86.RIL RESULT.IR
IF ERRORLEVEL 1 GOTO FAILED
IRWIDE RESULT.IR RESULT.ASM
IF ERRORLEVEL 1 GOTO FAILED
ASMAKEEP RESULT.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM I0.COM >NUL
ECHO PASS IR86 INITIAL BUILD
R0 ASM86.RIL RESULT.IR
IF ERRORLEVEL 1 GOTO FAILED
IRWIDE RESULT.IR RESULT.ASM
IF ERRORLEVEL 1 GOTO FAILED
ASMAKEEP RESULT.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM A0.COM >NUL
ECHO PASS ASM86 INITIAL BUILD
R0 RILL.RIL RESULT.IR
IF ERRORLEVEL 1 GOTO FAILED
I0 RESULT.IR RESULT.ASM
IF ERRORLEVEL 1 GOTO FAILED
A0 RESULT.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM R1.COM >NUL
ECHO PASS RILL GENERATION 1
R0 IR86.RIL RESULT.IR
IF ERRORLEVEL 1 GOTO FAILED
I0 RESULT.IR RESULT.ASM
IF ERRORLEVEL 1 GOTO FAILED
A0 RESULT.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM I1.COM >NUL
ECHO PASS IR86 GENERATION 1
R0 ASM86.RIL RESULT.IR
IF ERRORLEVEL 1 GOTO FAILED
I0 RESULT.IR RESULT.ASM
IF ERRORLEVEL 1 GOTO FAILED
A0 RESULT.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM A1.COM >NUL
ECHO PASS ASM86 GENERATION 1
R1 RILL.RIL RESULT.IR
IF ERRORLEVEL 1 GOTO FAILED
I1 RESULT.IR RESULT.ASM
IF ERRORLEVEL 1 GOTO FAILED
A1 RESULT.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM R2.COM >NUL
ECHO PASS RILL GENERATION 2
R1 IR86.RIL RESULT.IR
IF ERRORLEVEL 1 GOTO FAILED
I1 RESULT.IR RESULT.ASM
IF ERRORLEVEL 1 GOTO FAILED
A1 RESULT.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM I2.COM >NUL
ECHO PASS IR86 GENERATION 2
R1 ASM86.RIL RESULT.IR
IF ERRORLEVEL 1 GOTO FAILED
I1 RESULT.IR RESULT.ASM
IF ERRORLEVEL 1 GOTO FAILED
A1 RESULT.ASM RESULT.COM
IF ERRORLEVEL 1 GOTO FAILED
COPY RESULT.COM A2.COM >NUL
ECHO PASS ASM86 GENERATION 2
ECHO BUILDS COMPLETE - COMPARE THE GENERATIONS
GOTO END
:MISSING
ECHO MISSING TESTED ASMAKEEP.COM
GOTO END
:FAILED
ECHO FAIL - STOP AT THE FIRST TOOL ERROR
:END
```
